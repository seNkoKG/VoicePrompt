A privacy model you can explain

Local audio.
Visible choices.

The default path is microphone to local GPU to focused app. There is no account, analytics SDK, hidden upload, or saved recording.

  • Optional AI cleanup sends completed text only; selected text is sent only after an explicit Command or Ukaz action.
  • Compatible server mode sends audio only to the server you configure.
  • Manual update checks and confirmed downloads contact only the official GitHub release endpoints.
